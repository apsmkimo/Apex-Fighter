# Apex Fighter 專案計畫

## 目標

做出一款雷電風格的 Android 直向射擊遊戲。第一個版本（v0.1）有 1 台戰機、1 個完整關卡，架構可以輕鬆擴充成多機體、多關卡。

## 設計決策

| 項目 | 決定 | 原因 |
|---|---|---|
| 引擎 | Godot 4.4+，GDScript | 免費、2D 強、APK 小、內建 Android 匯出 |
| 畫面 | 直向 720×1280，`keep_width` 縮放 | 寬度固定，較長的手機自動多看到上下空間 |
| 操作 | 拖曳相對移動 + 自動射擊 + 炸彈按鈕 | 手指不會遮住戰機，手機射擊遊戲的主流手感 |
| 資料 | 全部用自訂 Resource（.tres） | 加內容＝加檔案，不用改程式 |
| 判定 | 玩家判定半徑 6px，遠小於機身 | 彈幕遊戲手感的關鍵 |
| 效能 | 子彈物件池（預建 400 發） | 手機上避免大量產生/刪除造成卡頓 |
| 系統溝通 | `Events` 訊號總線 | UI、音效、分數互不依賴，方便替換 |

## 第一台戰機：FALCON

- 武器 Vulcan，4 段火力：2 發直射 → 3 發 → 4 發小擴散 → 6 發大擴散
- 3 條命、3 顆炸彈（上限 5），被擊落火力降 1 級
- 炸彈：清除所有敵彈、對畫面內敵機造成 80 傷害、1.5 秒無敵

## 第一關：STAGE 1（約 50 秒道中 + Boss）

| 時間 | 內容 |
|---|---|
| 2–8s | 小飛機 Dart 直線、蛇行編隊（自機狙單發） |
| 11–13s | 必掉火力的 Dart、第一台砲台 Turret（5 發扇形彈） |
| 15–23s | 左右對稱斜飛、雙砲台、對稱蛇行 |
| 27s | 炸彈運輸機（必掉炸彈，3 連發自機狙） |
| 30–46s | 密集編隊、三砲台、最後一波混合 |
| Boss | VIOLET FORTRESS，900 HP，三階段：3 連發 + 環形彈 → 螺旋彈 + 自機狙 → 20 方向旋轉環 + 7 發扇形 + 3 連發 |

道具：P（火力）、B（炸彈）、M（勳章 1000 分）。火力或炸彈已滿時改給分數。
